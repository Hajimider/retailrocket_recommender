# 下一件未看过商品推荐设计

## 目标

输入同一会话最近 3 条浏览或加购行为，推荐之后第一个尚未在观察窗口出现的商品。结果中不得包含输入商品。

## 数据口径

- 观察窗口仍为会话前 3 条非交易行为。
- 从第 4 条行为开始向后查找，取第一个不在观察窗口商品集合中的商品作为目标。
- 没有后续新商品的会话不进入样本。
- 继续按访客划分 train / val / test，召回统计只使用训练观察窗口。

## 召回与排序

- 最近交互商品只作为共现召回的种子，不直接进入候选集。
- 共现、类目热门和全站热门候选均过滤观察窗口商品。
- 移除只对重复推荐有意义的 `source_recent`、`seen_count` 和 `same_as_last` 特征。
- 保留候选商品类目和最相关的观察商品，用于页面解释。

## 页面与接口

- 默认输入来自真实测试会话，不再使用连续占位 ID。
- `GET /examples` 返回若干真实观察窗口，页面按钮可切换示例。
- 推荐表展示商品 ID、类目 ID、相对推荐分和推荐依据。
- `POST /recommend` 保持原请求格式，响应增加 `categoryid`、`related_itemid` 和 `reason_zh`。

## 验收

- 离线和在线候选均不包含输入商品。
- 目标商品一定未在前三条观察行为中出现。
- 真实示例来自 test 分区且不暴露目标商品。
- 重跑全量数据，使用新实测指标更新 README。
