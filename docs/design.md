# RetailRocket 会话商品推荐系统设计

## 任务定义

以同一会话前三条非交易行为作为观察窗口，从后续行为中寻找第一个尚未在观察窗口出现的商品作为目标，输出下一件未看过商品的 Top-K 推荐。没有后续新商品的会话不进入样本。

## 数据边界

- 30 分钟无行为视为新会话。
- 同一访客只属于训练集、验证集或测试集中的一个集合。
- 商品共现、热门商品和类目热门商品仅由训练集合的前三条观察行为统计。
- 训练、验证和测试均不补入目标商品；排序器只使用自然召回成功的训练会话。
- 最近交互商品只用于查询共现邻居，候选集合统一排除前三条已交互商品。
- 商品类目来自公开商品属性文件；匿名长尾属性不直接展开。

## 推荐流程

1. 最近交互商品、商品共现、类目热门和全局热门组成候选集。
2. 热门排序和混合召回启发式排序作为无需训练的基线。
3. LR 作为可解释的点式排序基线。
4. LightGBM Ranker 学习候选商品的相对顺序，并用少量参数组合调优。
5. 四种方法均进入验证集比较，以 NDCG@10 选择最终方法，测试集只用于一次最终评估。

## 评价与接口

- 候选阶段：Candidate Recall。
- 排序阶段：Recall@5、Recall@10、MRR@10、NDCG@10、Coverage@10。
- 在线接口输入 3 条行为，返回 Top-K 未看过商品的商品 ID、类目 ID、推荐分数和推荐依据。
- 页面默认展示真实测试会话，并支持通过 `GET /examples` 切换示例。
- 页面只展示最终排序模型，不提供多模型切换。

## 约束

- 新建 `retailrocket_recommender/`，不修改旧项目。
- CPU 训练和推理。
- IDE 入口只保留快速模式、Top-K 和候选数量等少量主要参数。
- 不引入 Transformer、向量数据库、消息队列或分布式训练。
